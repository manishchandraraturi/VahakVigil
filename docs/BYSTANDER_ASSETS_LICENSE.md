# VahakVigil Bystander / First-Aid Visual Assets Documentation

## Overview
This document records the provenance, licensing, and design rationale for the emergency visual triage assets bundled in the VahakVigil Android application (`app/src/main/res/drawable/`).

All assets are bundled offline as native Android Vector Drawables (`VectorDrawable`). The application performs **zero** runtime network downloads or remote hotlinking.

## License Details
All visual vector paths in this asset set were authored directly for the VahakVigil project following international emergency safety signs (ISO 7010) and standard pre-hospital trauma protocols. They are dedicated to the public domain under the **Creative Commons Zero 1.0 Universal (CC0 1.0)** public domain dedication and licensed under the project's **Apache License 2.0**, allowing unrestricted redistribution, modification, and offline packaging within open-source and commercial software without royalty or attribution barriers.
